CMPU4003 Advanced Databases

Week 1

What are we doing this week?

This week introduces the Advanced Databases module and reviews some of the relational database and SQL knowledge that we will build on during the semester.

We will set up PostgreSQL and begin working with the Campus Events database, which will be used as a common case study throughout the module.

We will also introduce the main themes of the module and consider why applications may need different approaches to storing, accessing and processing data.

Lab Class

Week 1 Lab: PostgreSQL setup and review of relational database and SQL skills using the Campus Events database.

The lab will also introduce the case study that we will use to explore different database technologies and approaches during the semester. It will also pose some questions to kick-start your thinking about the concepts we will cover in the module.

Lecture Notes

Lecture 1: Introduction to Advanced Databases

In the first lecture, we will introduce the module and look at how Advanced Databases builds on the database knowledge and skills developed in earlier modules.

Using the Campus Events application as an example, we will consider different data requirements and why a relational database may not always be the only approach required.

The lecture will introduce some of the main concepts that will be explored during the module, including different data models, access paths, in-memory databases, distribution, replication, partitioning and vector search.

The lecture will also introduce how the assessment for the module will work.
